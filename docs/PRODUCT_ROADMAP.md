# Product Roadmap — TransitIQ TMS

**Long-Term Vision:** The Autonomous Transportation Operating System for India and Emerging Markets.

---

## Roadmap Phases

### Phase 1: Foundation & Core TMS (Delivered in v1.0.0)
- ✅ Multi-tenant PostgreSQL architecture with Row Level Security (RLS).
- ✅ 10 interconnected operational modules from order creation to invoice audit.
- ✅ AI Exception Manager with explainable risk scoring (0-100) and human approval.
- ✅ Configurable multi-attribute carrier procurement engine.
- ✅ Grounded AI Operations Copilot with clickable shipment citations.

### Phase 2: Live IoT & Highway Ecosystem Integrations (Q2 2027)
- 🔄 Native ULIP (Unified Logistics Interface Platform) API integration for NIC e-way bill verification.
- 🔄 Direct NPCI FASTag API integration for sub-second toll plaza GPS timestamps.
- 🔄 Commercial telematics hardware adapters (BlackBuck, Intangles, LocoNav, Trimble).
- 🔄 WhatsApp Conversational Bot for truck drivers (multilingual Hindi, Tamil, Telugu voice notes).

### Phase 3: Autonomous Dynamic Load Matching & Spot Procurement (Q4 2027)
- ⏳ Autonomous reverse bidding auction for spot freight corridors.
- ⏳ Predictive backhaul empty-miles matching algorithms.
- ⏳ Dynamic fuel index pricing linked to IOCL daily diesel wholesale rates.
- ⏳ Embedded freight financing and instant carrier factoring upon verified e-POD upload.
